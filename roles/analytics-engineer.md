# Analytics Engineer

## Mô tả vai trò

Cầu nối giữa Data Engineer và Data Analyst — biến dữ liệu thô thành data models sạch, đáng tin cậy, sẵn sàng cho phân tích.

## Trách nhiệm chính

- Xây dựng và maintain data models (staging, intermediate, marts)
- Định nghĩa metrics layer và business logic
- Đảm bảo data quality thông qua testing
- Viết documentation cho data models
- Thiết kế semantic layer cho self-service analytics
- Collaborate với stakeholders để hiểu business requirements

## Kỹ năng cần thiết

### Technical

- SQL (advanced)
- dbt (core tool)
- Data modeling (dimensional, Data Vault)
- Git & version control
- Data testing & validation
- BI tools (hiểu cách end-user consume data)
- Python (basic - intermediate)
- Jinja templating

### Soft skills

- Business acumen
- Communication (translate giữa technical và business)
- Documentation mindset
- Collaboration cross-functional

## Tools thường dùng

- dbt (dbt Core / dbt Cloud)
- Git
- SQL IDE (DataGrip, DBeaver)
- BI tools (Looker, Metabase, Power BI)
- Data catalog (dbt docs, Atlan, DataHub)

## Roadmap

1. **Junior** — SQL vững, hiểu dbt basics, viết staging models, data testing
2. **Mid** — Thiết kế marts, metrics layer, CI/CD cho dbt, mentoring
3. **Senior** — Data modeling strategy, semantic layer design, cross-team standards, data mesh ownership
