# Data Analytics

## Mô tả vai trò

Phân tích dữ liệu để tìm insight, hỗ trợ ra quyết định kinh doanh.

## Trách nhiệm chính

- Phân tích dữ liệu theo yêu cầu business
- Xây dựng dashboard và báo cáo
- Định nghĩa metrics và KPIs
- Ad-hoc analysis
- Data storytelling

## Kỹ năng cần thiết

### Technical

- SQL (intermediate - advanced)
- Excel / Google Sheets
- BI tools (Power BI, Tableau, Looker)
- Python / R (basic - intermediate)
- Statistics cơ bản

### Soft skills

- Business acumen
- Communication & presentation
- Critical thinking

## Roadmap

1. **Junior** — SQL, Excel, BI tool cơ bản, hiểu business metrics
2. **Mid** — Advanced SQL, dashboard design, statistical analysis
3. **Senior** — Data strategy, stakeholder management, mentoring
