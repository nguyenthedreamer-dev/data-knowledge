# Data Scientist

## Mô tả vai trò

Áp dụng thống kê, machine learning để giải quyết bài toán kinh doanh phức tạp.

## Trách nhiệm chính

- Xây dựng predictive models
- Feature engineering
- A/B testing & experimentation
- Research và áp dụng thuật toán mới
- Model deployment & monitoring

## Kỹ năng cần thiết

### Technical

- Python (advanced)
- Statistics & probability
- Machine Learning (scikit-learn, XGBoost)
- Deep Learning (TensorFlow, PyTorch)
- SQL
- MLOps basics

### Soft skills

- Research mindset
- Communication (giải thích kết quả cho non-technical)
- Collaboration

## Roadmap

1. **Junior** — Statistics, Python, ML cơ bản, EDA
2. **Mid** — Advanced ML, deep learning, model deployment
3. **Senior** — Research, ML system design, mentoring, business impact
