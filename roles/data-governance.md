# Data Governance

## Mô tả vai trò

Quản trị dữ liệu toàn tổ chức, đảm bảo chất lượng, bảo mật và tuân thủ quy định.

## Trách nhiệm chính

- Xây dựng data policies và standards
- Quản lý data catalog
- Đảm bảo data quality
- Data lineage tracking
- Compliance (GDPR, regulations)
- Data ownership & stewardship framework

## Kỹ năng cần thiết

### Technical

- Data catalog tools (Collibra, Alation, DataHub)
- Data quality frameworks
- Metadata management
- SQL (intermediate)
- Data lineage tools

### Soft skills

- Policy writing
- Stakeholder management
- Change management
- Cross-functional collaboration

## Roadmap

1. **Junior** — Hiểu data governance concepts, data catalog, data quality basics
2. **Mid** — Implement governance framework, policy creation, tool administration
3. **Senior** — Enterprise governance strategy, compliance leadership, organizational change
