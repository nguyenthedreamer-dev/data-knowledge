# Data Architect

## Mô tả vai trò

Thiết kế kiến trúc tổng thể cho hệ thống dữ liệu, đảm bảo scalability, security và governance.

## Trách nhiệm chính

- Thiết kế data architecture (warehouse, lake, lakehouse)
- Định nghĩa data standards và conventions
- Đánh giá và lựa chọn công nghệ
- Data modeling (conceptual, logical, physical)
- Phối hợp cross-team để đảm bảo tính nhất quán

## Kỹ năng cần thiết

### Technical

- Data modeling (Data Vault, Kimball, Inmon)
- Cloud architecture (AWS/GCP/Azure)
- Database systems (OLTP, OLAP)
- Data integration patterns
- Security & compliance
- Metadata management

### Soft skills

- Strategic thinking
- Leadership & influence
- Communication với stakeholders ở nhiều level

## Roadmap

1. **Mid-level** — Nắm vững data modeling, cloud services, hands-on implementation
2. **Senior** — Enterprise architecture, technology evaluation, cross-team alignment
3. **Principal** — Data strategy, innovation, organizational influence
