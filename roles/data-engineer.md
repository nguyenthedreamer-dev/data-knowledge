# Data Engineer

## Mô tả vai trò

Xây dựng và vận hành hạ tầng dữ liệu, đảm bảo dữ liệu sẵn sàng cho phân tích và ra quyết định.

## Trách nhiệm chính

- Thiết kế và xây dựng data pipeline (ETL/ELT)
- Quản lý data warehouse / data lake
- Đảm bảo data quality và monitoring
- Tối ưu hiệu năng query và storage
- Phối hợp với Data Analyst, Data Scientist để cung cấp dữ liệu

## Kỹ năng cần thiết

### Technical

- SQL (advanced)
- Python / Scala
- Apache Spark, Airflow, Kafka
- Cloud platforms (AWS/GCP/Azure)
- dbt, data modeling
- Docker, CI/CD

### Soft skills

- Problem solving
- Communication
- Documentation

## Roadmap

1. **Junior** — SQL, Python cơ bản, hiểu ETL concepts
2. **Mid** — Xây pipeline end-to-end, data modeling, cloud services
3. **Senior** — System design, optimization, mentoring, data architecture decisions
