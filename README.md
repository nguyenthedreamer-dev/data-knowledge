# Data Knowledge

Repo chứa toàn bộ kiến thức về lĩnh vực dữ liệu, các vị trí trong ngành, và skill files để huấn luyện AI.

## Cấu trúc

```
data-knowledge/
├── domains/          # Kiến thức theo lĩnh vực chuyên môn
├── roles/            # Roadmap & mô tả các vị trí
├── skills/           # Skill files (.md) cho AI training
└── references/       # Thuật ngữ, tài liệu tham khảo
```

## Các vị trí quan tâm

- Data Engineer
- Data Analytics
- Analytics Engineer
- Data Architecture
- Data Science
- Data Governance

## Cách sử dụng

- `domains/` — Đọc để nắm kiến thức nền tảng theo từng mảng
- `roles/` — Xem roadmap, kỹ năng cần thiết cho từng vị trí
- `skills/` — Dùng làm steering/skill files để huấn luyện AI assistant
- `references/` — Tra cứu thuật ngữ, best practices, tài liệu tham khảo
