# Glossary - Thuật ngữ dữ liệu

## A

- **Ad-hoc analysis** — Phân tích theo yêu cầu cụ thể, không định kỳ

## B

- **Batch processing** — Xử lý dữ liệu theo lô, theo lịch

## C

- **CDC (Change Data Capture)** — Kỹ thuật bắt thay đổi dữ liệu từ source

## D

- **Data Catalog** — Hệ thống quản lý metadata, giúp tìm kiếm và hiểu dữ liệu
- **Data Lake** — Kho lưu trữ dữ liệu thô ở mọi format
- **Data Lakehouse** — Kết hợp data lake + data warehouse
- **Data Lineage** — Theo dõi nguồn gốc và luồng di chuyển của dữ liệu
- **Data Vault** — Phương pháp modeling cho enterprise data warehouse
- **Dimensional Modeling** — Phương pháp modeling theo fact/dimension (Kimball)

## E

- **ELT** — Extract, Load, Transform
- **ETL** — Extract, Transform, Load

## K

- **KPI** — Key Performance Indicator

## M

- **MDM (Master Data Management)** — Quản lý dữ liệu chủ

## O

- **OLAP** — Online Analytical Processing
- **OLTP** — Online Transaction Processing
